# Anti-Slop — дефолты генерации интерфейсов

**Это ДЕФОЛТЫ, а не запреты.** Явная просьба пользователя перебивает любой пункт ниже.
Если он осознанно просит glassmorphism, градиент или центрирование — делай и не спорь.
Список задаёт исходную точку «как рисовать, когда уточнений нет», чтобы из коробки
не лез шаблонный AI-вид.

Формат пункта: **паттерн** → почему slop → что вместо.

---

1. **Эмодзи как иконки** (🚀 в кнопке, ✨ в заголовке) → дёшево, нет консистентности → нормальный icon-set (Lucide / Phosphor).

2. **Карточка-штамп** (скругление + тень + бордер + иконка-кружок одновременно) → перегруз, «бутстрап 2015» → выбери ОДИН способ выделения.

3. **Фиолетово-синий дефолт-градиент** (`#667eea → #764ba2` и родня) → дефолт всех LLM → осознанный цвет из проектного слоя.

4. **Центрированный текст везде** → нет ритма чтения → выравнивание по левому краю по умолчанию.

5. **Случайные размеры/отступы** (`17px`, `13px`, `margin: 23px`) → ломает шкалу → только значения из spacing/type scale.

6. **Декоративные иконки у каждого пункта списка** → визуальный шум → иконка только если несёт смысл.

7. **Три одинаковые карточки-заглушки** («Fast / Secure / Easy») → шаблон лендинга → реальная иерархия по важности.

8. **Glassmorphism / blur без причины** → тренд ради тренда → depth только если решает задачу.

9. **Чрезмерные тени** (`box-shadow` на всём) → «парящий» интерфейс → тень = высота в иерархии, экономно.

---

## Few-shot: плохо → хорошо

Иконки (п.1) — корень в том, что без библиотеки модель скатывается в эмодзи:

```jsx
// ПЛОХО — эмодзи как иконка
<button>🚀 Запустить</button>
<li>✨ Быстро</li>

// ХОРОШО — icon-set (lucide-react)
import { Rocket, Zap } from "lucide-react";
<button><Rocket size={16} /> Запустить</button>
<li><Zap size={16} /> Быстро</li>
```

Если библиотеки нет и поставить нельзя — текст без иконки лучше эмодзи.

Градиент-дефолт (п.3):

```css
/* ПЛОХО — дефолтный LLM-градиент */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* ХОРОШО — осознанный цвет из проектного слоя (токен) */
background: var(--surface-100);
```
