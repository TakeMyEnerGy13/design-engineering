# design-engineering

Claude Code skill: оркестратор дизайн-работы для UI-задач. Главная идея — **обязательный якорь вкуса** перед любой генерацией: без конкретного референса любой сгенерированный UI сводится к безликому «AI-слопу» (indigo-градиенты, rounded-2xl, карточки-штампы).

## Как работает

1. **Якорь вкуса (обязательный гейт)** — референс-скриншот от пользователя, `design.md` проекта или явно названный ориентир. Вёрстка вслепую запрещена.
2. **Правила** — `design-core.md` (основы) + `anti-slop.md` (запрещённые паттерны).
3. **Провижининг ассетов** — иконки, шрифты, компоненты и motion закрываются *до* генерации, чтобы модели было из чего собирать.
4. **Генерация** — делегируется скиллу `frontend-design` с уже заданным якорем.
5. **Полировка** — `impeccable`, только по запросу.

## Состав

| Файл | Назначение |
|---|---|
| `SKILL.md` | Точка входа: флоу, гейты, red flags |
| `design-core.md` | Базовые правила дизайна |
| `anti-slop.md` | Анти-паттерны генеративного UI |
| `motion.md` | Анимации: CSS-дефолты, когда брать `motion` |
| `project-template.md` | Шаблон проектного `design.md` |

## Установка

```bash
git clone https://github.com/<user>/design-engineering ~/.claude/skills/design-engineering
```

Claude Code подхватит скилл автоматически. `design-core.md` и `anti-slop.md` — портативный markdown: их можно скармливать и другим агентам (Codex и т.п.) явной командой.

## Зависимости

Скилл рассчитан на наличие скилла `frontend-design` (генерация) и опционально `impeccable` (полировка). Без них работает как набор правил, но флоу делегирования будет неполным.
